Låt agenter sköta flödet

En agent (Cursor, n8n, egen bot) kan rulla in taxibolag från lead till aktiverad enhet — utan manuell admin.

1. Skapa bolag

POST /api/agent/provision
Authorization: Bearer AGENT_API_KEY
{
  "name": "Malmö Taxi AB",
  "email": "trafik@malmotaxi.se",
  "password": "tillfalligt-losen",
  "orgNumber": "556000-0000",
  "seats": 8,
  "devices": [
    { "label": "Bil 1", "kind": "shared" },
    { "label": "Ahmed", "kind": "driver" }
  ]
}

Returnerar företags-ID, dashboard-session tips, enhetslänkar och QR-URL:er.

2. Starta betalning (valfritt)

POST /api/agent/checkout
Authorization: Bearer AGENT_API_KEY
{ "companyId": "co_…", "seats": 8 }

Med Stripe → Checkout-URL. Utan Stripe → aktiveras direkt (bra för demo/agenter i test).

3. Skicka länkar till förare

Agenten SMS:ar eller mejlar appUrl / QR. När föraren öppnar länken aktiveras enheten automatiskt.

API-nyckel

Sätt AGENT_API_KEY i serverns miljö. Utan nyckel är agent-endpoints avstängda (säkerhet).

Ägare (OWNER_EMAIL) är alltid gratis och kan ha obegränsat antal enheter.
