Datapolicy

Senast uppdaterad: augusti 2026. Taxi Tips drivs av A2M Tech (Malmö).

Vad vi samlar in

  • Kontouppgifter: bolagsnamn, e-post, lösenord (hashat), organisationsnummer.
  • Förartelefoner: bolagskod, telefonetikett, notispreferenser, push-token.
  • Användning: vilka orter ni följer, tekniska loggar för felsökning.
  • Betalning: hanteras av Stripe (kort/Klarna/Swish) — vi sparar inte kortnummer.

Varför

För att leverera live-signaler om var taxi behövs, skicka notiser ni valt, fakturera abonnemang och ge support.

Datakällor

Trafikstörningar och väginfo hämtas från Trafiklab/Trafikverket. Evenemang kan komma från Ticketmaster. Uppgifterna filtreras till taxirelevanta signaler för era orter.

Delning

Vi säljer inte era uppgifter. Underleverantörer (t.ex. hosting, Stripe, push) får bara det som behövs för tjänsten.

Lagring & rättigheter

Ni kan begära utdrag, rättelse eller radering via hej@taxiprognos.se. Kontot kan avslutas när ni vill. Förartelefon kan avregistreras i appen.

Cookies & analys

Nödvändiga cookies behövs för inloggning och säkerhet. Om du godkänner analyscookies använder vi Firebase / Google Analytics (GA4) för att förstå hur landningssida och app används (sidvisningar, knappar, enhetstyp). Du kan när som helst ändra valet via Cookieinställningar. IP anonymiseras där det stöds.

Push-notiser (FCM)

Push skickas via Firebase Cloud Messaging. Token lagras kopplad till er förartelefon och används bara för de notistyper och orter ni valt.
